# Changelog — dictate-swift

Нативное приложение Dictate для macOS — переписывание [kkdclaw/dictate](https://github.com/kkdclaw/dictate) (Python) на Swift.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
До 1.0.0 номера идут по фазам: **0.1** — рабочая диктовка (Ф1), **0.2–0.9** — догоняем Python-версию по функциям (Ф2), **1.0.0** — заменяет Python-версию на всех машинах (Ф3). MINOR — новые возможности, PATCH — исправления.

Версии 0.1.0–0.4.0 — вехи 14.11.2026: сборки тех дней показывали версию 0.0.0, файл `VERSION` ведётся с 0.5.0.

Текущая версия — файл `VERSION`; видна в меню приложения. Релиз — `./release.sh X.Y.Z`, публикация с архивом для автообновления — `./publish.sh`, сборка — `./build.sh [--install]`.

## [0.6.3] — 2026-11-18
### Исправлено
- В приложениях на Electron (Mattermost и подобные) капсула появлялась внизу посередине экрана, а не у курсора: у пустого поля они не сообщают, где стоит курсор. Теперь в таком случае капсула встаёт над самим полем ввода, у его левого края.

## [0.6.2] — 2026-11-16
### Исправлено
- С AirPods терялось начало фразы: при каждом нажатии macOS заново включает в наушниках режим гарнитуры и 0,2–1,3 с отдаёт вместо звука тишину. Теперь, пока микрофон подключается, капсула серая и звука начала нет — звук и цвет появляются, когда пошёл настоящий звук. Отпустили клавишу раньше — в журнале «микрофон не успел включиться», а не «захват пустой».
### Добавлено
- «Настройки → Держать микрофон после диктовки» (по умолчанию 1 мин; 15 с … 5 мин или «Не держать»): после фразы микрофон закрывается не сразу, и следующая фраза серии начинается без задержки. Цена — индикатор микрофона и режим гарнитуры AirPods на это время.
- В журнале у строки «Диктовка:» — «микрофон через N с», если запись ждала, пока микрофон включится.
### Исправлено также
- Регулярная проверка состояния (раз в 3 с) могла закрыть микрофон посреди записи отпечатка голоса.

## [0.6.1] — 2026-11-16
### Исправлено
- Горячая клавиша молча переставала работать после смены микрофона (отключились или подключились AirPods, пока микрофон закрыт): движок записи помнил формат прежнего входа, macOS отказывала в открытии на каждом нажатии, и помогал только перезапуск. Теперь при смене входа поток создаётся заново, а неудачное открытие пробуется ещё раз с нуля.
- Ошибки открытия микрофона больше не теряются: причина пишется в журнал («Микрофон: не открылся — …») и звучит сигнал ошибки, а не тишина.

## [0.6.0] — 2026-11-15
Первая публичная версия: исходники открыты, история git начата заново без личных данных автора.
### Добавлено
- Пункт «Помощь» в меню: справка по всем функциям (как диктовать, значки и капсула, голосовые команды, стили и чистка, окно постобработки, модели, словарь, мой голос, история, настройки, разрешения, где данные, если что-то не так) — локальная страница со светлой и тёмной темой.
- Из Python-версии в меню вернулись: «Язык распознавания» (русский / English / автоопределение, под «Модели…»; встроенный распознаватель macOS перезагружается под новый язык); слои словаря — «Слой для «приложение»», «Слой по умолчанию», «Открыть слой», «Папка слоёв (terms.d)», строка «Сейчас» с действующим слоем; «Звуки» подменю — свой системный звук или «Без звука» на начало записи, вставку и ошибку, выбранный сразу звучит; «Показать пример (5 с)» в «Капсуле записи».
### Исправлено
- Звук события выбирался по имени звука: при одинаковых звуках на разные события играла не та громкость — теперь по событию.
### Изменено
- «О программе» — версия, «Проверить обновления», «Автообновление» и период (раз в день / неделю / месяц), журнал, перезапуск; переход на Python-версию убран. Автообновление из GitHub Releases снова включено: репо публичный, токен не нужен; проверка в простое, ставится только сборка с той же подписью; без сети фоновая проверка пишет в журнал, а не показывает окно.

## [0.5.0] — 2026-11-15
Выбор моделей по итогам сравнения на корпусе диктовок; новое окно «Модели» и меню.
### Добавлено
- Меню перестроено по смыслу: сверху состояние (модель, чистка, стиль для текущего приложения), «Диктовка включена» и предупреждения (нет разрешений, диктует Python-версия); дальше ежедневное — «Стиль и чистка», «Голосовые команды», «История»; затем «Модели…», «Мой голос», «Словарь терминов»; внизу «Настройки» (хоткей, микрофон, капсула, звуки, буфер, аудио, запуск при входе, разрешения), «Состояние…», «О программе» (обновления, Python-версия, журнал, папка, перезапуск), «Выход».
- Новое окно «Модели» на SwiftUI: вкладки «Распознавание речи» / «Чистка текста», карточка на модель — назначение, цифры сравнения колонками (время, ошибки, английские слова / «ё», паразиты, вес), состояние, главная кнопка с иконкой (✓ Выбрать / ⬇ Скачать) и иконки управления прямо на карточке — 📁 Finder, 🗑 удалить перегнанную копию (приглушена, если нечего), 🌐 Hugging Face — с подсказками, без контекстного меню; активная подсвечена и всегда первой в списке; внизу — откуда цифры и ссылка на страницу сравнения.
- Окно «Модели» по сравнению 14.11 (224 диктовки, 150 фраз чистки): в подписях — замеры; распознавание — turbo, codeswitch-turbo, podlodka-turbo, large-v3, **Parakeet Ultra и Fluid Speech Pro** (новый движок через FluidAudio, 0,05–0,06 с, без словаря), Apple; чистка — Qwen3-4B, **RuadaptQwen3-4B**, Qwen3-1.7B, GigaChat (пока не выбирается). Убраны large-v3 Russian, Qwen3.5-4B/9B, Gemma 4.
- Конвертер Whisper из формата Hugging Face transformers в ggml (порт `convert-h5-to-ggml.py`, результат совпадает с ним потензорно) — codeswitch и podlodka перегоняются из кэша по кнопке «Выбрать».

## [0.4.0] — 2026-11-14
Паритет с Python-версией по хоткею, истории, обновлениям и голосу.
### Добавлено
- Встроенный распознаватель macOS на выбор в «Моделях» («Apple (встроенный)», `asr_model: apple/dictation`): DictationTranscriber на устройстве, модель ставит macOS; whisper при этом выгружается. На корпусе 0,14 с, но WER 17,6 % против 6,2 %, словарь — подсказкой `contextualStrings` (термины 5/12), пунктуации для русского нет, «сомнений» нет. macOS 26+.
- **Отпечаток голоса** «Пропускать только мой голос» (логика Python-версии: окна 3 с / шаг 1,5 с, порог от разброса 0,28…0,40, строгость 0,55/0,40/0,28, окно записи с текстом для чтения и проверка «узнаю ли я тебя»); эмбеддинг — WeSpeaker v2 через FluidAudio 0.18.3 (CoreML) вместо speechbrain ECAPA, отпечаток записывается заново. Замер: свой голос 0,76–0,91, синтезированные чужие −0,07…0,04. Меню «Мой голос», строка в «Состоянии».
- Автообновление из GitHub Releases (как у Python-версии: «О программе» → «Обновить», галка «Автообновление», период день/неделя/месяц, только в простое): ставится собранное .app, только если оно подписано тем же сертификатом; приватный репо — токен только на чтение в связке ключей (служба `dictate-swift-github`). Выпуск — `./release.sh X.Y.Z` → `./publish.sh`.
- **История**: окно «Поиск истории» и «Статистика» (порт `dashboard.py`: те же подсчёты, SVG-графики и шаблон страницы, WKWebView); разовый импорт истории и аудио Python-версии; галка «Хранить аудио диктовок» (audio/<id>.wav, 16 кГц PCM16, потолок `audio_max_mb`) и ▶ в поиске; последние 5 диктовок в меню (клик — скопировать).
- Автословарь `auto_terms.txt` (порт `build_auto_terms`): латиница в ≥ 2 диктовках + устоявшиеся исправления чистки; пересобирается при каждом запуске и по кнопке; на истории автора состав = Python (19 из 19).
- Горячая клавиша как в Python-версии: короткий тап (< 0,35 с) — запись до второго тапа, Esc — отмена, нажатие другой клавиши при зажатом модификаторе (⌘C на правом Command) — не диктовка; меню «Горячая клавиша» с пресетами, «Своё сочетание…» (окно захвата, порт `hotkeywindow.py`) и справкой.

Модели — из кэша Python-версии как есть, через mlx-swift-lm 3.32.3; на истории автора чистка дословно как у Python на 68 из 80. Голосовые команды стилей и «переведи» работают. Меню «Стиль и чистка», раздел «Чистка текста» в окне «Модели».
- Настройки новых функций дотягиваются из конфига Python-версии при запуске, если их ещё нет.

Разбор совпадает с Python-версией на 282 фразах. Стили и перевод — с чисткой текста.
- Защиты из Python-версии: эхо словаря на тихой записи, зацикливание на одном слове; короткая фраза — без точки в конце.
- Значки в меню-баре как у Python-версии: 🎙️ готов, 🟠 запись, ⏳ загрузка, ❌ ошибка, 🌙 выключено (⏸ — диктует Python-версия).

## [0.1.0] — 2026-11-14
Первая рабочая диктовка: хоткей → whisper.cpp со словарём → вставка; проба движков (Ф0).
### Добавлено
- Постоянная подпись: `build.sh` подписывает локальным сертификатом «Dictate Local Signing» — разрешения macOS переживают пересборки.
- Микрофон только во время записи (по умолчанию; `mic_mode`: `on_demand` / `always`, переключатель в меню) — индикатор микрофона не горит в простое.
- «Мониторинг ввода»: приложение само попадает в список Настроек (пробный перехват перед запросом).
- Иконка: белый микрофон и три строки текста с курсором на градиенте от кораллового к красному («голос становится текстом»); рисуется кодом — `tools/make-icon.swift`, `tools/make-icon.sh` → `Resources/AppIcon.icns`.
- **Диктовка (Ф1, первая веха):** зажал горячую клавишу — сказал — отпустил — текст вставлен. whisper.cpp (Metal) со словарём в `initial_prompt` (слои `terms.d` по приложению, бюджет 210 токенов — подсказка совпадает с Python-версией на 224 из 224 диктовок), вырезание петель и титров (порт `textclean.py` с его тестами), вставка ⌘V с возвратом буфера через 0,6 с, история в `history.sqlite3` той же схемы, звуки, журнал `dictate.log`.
- Хоткей в формате Python-версии (`alt_r`, `fn`, `ctrl+space`, `cmd+shift+d`…), перехват через CGEventTap.
- Микрофон держится открытым, пока диктовка включена; смена входа — переоткрытие потока; пустой захват (пик < 0,02) — звук ошибки и строка в журнале.
- Модель — из кэша Python-версии без скачивания: конвертер MLX → ggml на Swift (`MLXConverter`, safetensors и zip64-npz), побайтно как `tools/mlx2ggml.py`.
- Первый запуск: каталог `~/Library/Application Support/Dictate`, словарь, слои, сниппеты и настройки — из `~/dictate`.
- Сосуществование с Python-версией: пока она диктует — пауза ⏸; меню «Перейти на эту версию» выключает её её же галкой (`enabled: false` + перезапуск службы), «Вернуть Python-версию» — обратно.
- Меню: состояние, «Диктовка включена», разрешения (Микрофон, Мониторинг ввода, Универсальный доступ), словарь, история, «Запускать при входе», папка данных, журнал.
- Служебные режимы: `Dictate --convert [repo]`, `Dictate --transcribe manifest audioDir out.jsonl [dataDir]`.
- `tools/mlx2ggml.py`: перегоняет модели Whisper из кэша Python-версии (MLX, `~/.cache/huggingface`) в ggml для whisper.cpp — качать заново не нужно; turbo и large-v3 проверены на 224 диктовках.
- `bench/whisper-cpp` → `pkbench`: замер Parakeet TDT v3 через `parakeet.h` того же whisper.cpp.
- `bench/`: замер движков распознавания на реальных диктовках — whisper.cpp (Metal, `initial_prompt`) против mlx-whisper, сводка `score.py` (скорость, пустые, WER к эталону large-v3, термины словаря).
- Каркас: Swift Package (библиотека `DictateCore` + приложение `Dictate`), значок 🎤 в меню-баре с версией, сборка `Dictate.app` (`build.sh`), релиз (`release.sh`).
